关于本站

HALO Music 是一个轻量、简洁、跨平台的个人音乐空间：发现音乐、管理收藏、创建歌单、记录聆听。

你可以做什么

  • 发现音乐：推荐歌曲、热门榜单与热门歌手，也可以直接搜索想听的歌
  • 管理收藏：收藏喜欢的歌曲，创建自己的歌单，导入或导出平台歌单
  • 记录聆听：听歌总结与最近播放；支持 Windows、Android 客户端，iPhone 可添加到主屏幕

关于内容来源

HALO Music 只展示第三方平台公开的检索结果并代理播放地址，不存储、不制作任何音频文件。音乐、封面与歌词的版权归各平台及原作者所有，详见免责声明。

隐私政策

随 v{{APP_VERSION}} 更新。这份说明描述的是 Halo Music 当前实际的数据处理方式。

1. 我们收集什么

  • 账号信息：邮箱、用户名，以及密码的单向哈希（PBKDF2-SHA256，10 万次迭代加随机盐，不保存明文密码）；可选的显示名与头像图片地址。
  • Google 登录：接收 Google 提供的账号标识、已验证邮箱、昵称与头像地址，不接触你的 Google 密码。
  • 音乐库：收藏的歌曲与自建歌单，以 JSON 形式整体保存。
  • 听歌记录：曲目标识、歌名、歌手与播放时间，仅用于向你展示听歌总结与最近播放，不用于广告投放或用户画像。
  • 邮箱验证码：只保存验证码哈希、请求 IP 哈希与过期时间。验证码 10 分钟后失效；发送频控用的 IP 哈希 24 小时后清理，仅用于限制请求频率，不用于限制账号数量。
  • 缓存：搜索关键词缓存约 45 秒，音源解析结果最长 365 天（用于加速播放与避免重复解析），匿名访问也会产生。

2. 浏览器本地存储

主题偏好、歌单与播放队列的本地副本保存在 localStorage。登录态使用 HttpOnly Cookie hm_token（Secure、SameSite=Lax，30 天有效），页面脚本无法读取其内容。

3. 第三方服务

  • Cloudflare：页面托管、接口运行与数据库存储。
  • Resend：发送注册验证码邮件。
  • Google：OAuth 登录。
  • QQ 音乐、网易云音乐、汽水音乐、哔哩哔哩及其公开解析接口：搜索与播放；搜索关键词会发送给对应平台。

本站没有广告，也没有接入第三方统计或行为追踪脚本。

4. 数据用途

上述数据仅用于登录、同步收藏与歌单、向你展示听歌总结与最近播放、以及检索与播放内容。听歌记录只服务于你自己可见的统计功能，不用于广告投放、推荐营销或用户画像。搜索关键词与曲目标识会发送给对应的第三方平台以完成检索与播放。

5. 保留、导出与删除

账号数据保留到你主动注销。在「我的信息」中永久注销后，账号、收藏、歌单、听歌记录与会话会被删除，且无法恢复；Cloudflare 的底层备份副本可能在一段时间内仍保留历史快照，到期后自动清除。如需导出自己的收藏、歌单与听歌记录，可通过 GitHub Issues 提出请求。

6. 安全

全站使用 HTTPS，会话 Cookie 设置了 HttpOnly、Secure 与 SameSite，密码只保存哈希。但任何互联网服务都无法保证绝对安全，请不要复用其他网站的重要密码。

7. 未成年人

本项目为学习演示，不面向 14 岁以下儿童，也不会刻意收集其个人信息。

8. 变更与联系

政策如有变更会直接更新在本页；有疑问请通过 GitHub Issues 联系。
