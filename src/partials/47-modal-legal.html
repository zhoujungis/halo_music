关于本站

HALO Music 是一个音乐搜索与在线播放的演示项目：聚合 QQ 音乐、网易云音乐、汽水音乐和哔哩哔哩的公开数据，提供搜索、歌词、收藏、歌单与听歌统计。

主要功能

  • 多平台聚合搜索与在线播放，歌词逐行滚动
  • 收藏、自建歌单，导入或导出平台歌单
  • 听歌总结；支持 Windows、Android 客户端，iPhone 可添加到主屏幕全屏使用

技术说明

前端是纯静态页面，接口由 Cloudflare Pages Functions 提供，账号与音乐数据存放在 Cloudflare D1。iPhone 上不需要安装包，通过 Safari「添加到主屏幕」即可获得全屏体验。

隐私政策

随 v{{APP_VERSION}} 更新。这份说明描述的是 Halo Music 当前实际的数据处理方式。

1. 我们收集什么

  • 账号信息：邮箱、用户名，以及密码的单向哈希（PBKDF2-SHA256，10 万次迭代加随机盐，不保存明文密码）；可选的显示名与头像图片地址。
  • Google 登录：接收 Google 提供的账号标识、已验证邮箱、昵称与头像地址，不接触你的 Google 密码。
  • 音乐库：收藏的歌曲与自建歌单，以 JSON 形式整体保存。
  • 听歌记录：曲目标识、歌名、歌手与播放时间，用于生成「听歌总结」。
  • 注册 IP 哈希：注册时把客户端 IP 与服务器密钥做 SHA-256 哈希后保存，用于限制每个网络只能注册一个账号；不保存原始 IP。
  • 邮箱验证码：只保存验证码哈希、请求 IP 与过期时间，10 分钟后失效。
  • 缓存：搜索关键词与音源解析结果的短时缓存，匿名访问也会产生。

2. 浏览器本地存储

主题偏好、歌单与播放队列的本地副本保存在 localStorage。登录态使用 HttpOnly Cookie hm_token（Secure、SameSite=Lax，30 天有效），页面脚本无法读取其内容。

3. 第三方服务

  • Cloudflare：页面托管、接口运行与数据库存储。
  • Resend：发送注册验证码邮件。
  • Google：OAuth 登录。
  • QQ 音乐、网易云音乐、汽水音乐、哔哩哔哩及其公开解析接口：搜索与播放；搜索关键词会发送给对应平台。

本站没有广告，也没有接入第三方统计或行为追踪脚本。

4. 数据用途

上述数据仅用于登录、同步收藏与歌单、展示听歌总结、检索与播放内容，不用于广告投放或用户画像。

5. 保留与删除

账号数据保留到你主动注销。在「我的信息」中永久注销后，账号、收藏、歌单、听歌记录与会话会被删除，且无法恢复。

6. 安全

全站使用 HTTPS，会话 Cookie 设置了 HttpOnly、Secure 与 SameSite，密码只保存哈希。但任何互联网服务都无法保证绝对安全，请不要复用其他网站的重要密码。

7. 未成年人

本项目为学习演示，不面向 14 岁以下儿童，也不会刻意收集其个人信息。

8. 变更与联系

政策如有变更会直接更新在本页；有疑问请通过 GitHub Issues 联系。
