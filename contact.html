联系与反馈

Halo Music 是一个独立维护的个人项目。功能建议、问题反馈和版权相关请求都可以通过下面的渠道提交。

问题与建议

在 GitHub Issues 提交，附上问题的复现步骤、出现的页面和浏览器版本，会更容易定位。

提交 Issue →

也可以直接发邮件：edfc1582@shmarpe.resend.app（通常一到两天内回复）。

版权相关请求

如果你认为站内的检索结果或代理播放地址侵犯了你的权益，请在 Issue 中注明具体页面、歌曲信息与你的身份说明，核实后会及时移除相关结果。

本站不存储、不制作音频文件，只展示第三方平台公开的检索结果，详见免责声明。

数据导出与账号问题

需要导出收藏、歌单与听歌记录，或遇到账号异常，同样可以通过 Issues 说明情况并提供用户名（不要提供密码）。
