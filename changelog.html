更新日志

这里记录 Halo Music 的主要变更。完整记录可以在 GitHub Releases 查看。

v2.3 · 发现与统计

  • 榜单拆分为独立页面：热歌榜 / 新歌榜 / 飙升榜，数据每天凌晨更新一次
  • 发现页新增「推荐歌曲」「推荐歌手」与本地搜索历史
  • 「我的信息」重做为听歌分析：总时长、7 天趋势、收听时段、最常听歌手与歌曲
  • 音质标签改为只展示确认过的信息，无法确认时不显示「无损」
  • 播放器新增缓冲与失败状态，支持进度拖拽、音量快捷键与封面过渡

v2.2 · 播放体验与客户端

  • 试听片段自动切换完整音源，并记住替换关系
  • 播放失败自动跳到下一首，连续失败两次后停止
  • 全部列表的播放图标跟随播放状态切换
  • Android 客户端支持后台播放、锁屏与通知栏控制
  • 歌单支持描述与自动封面；下载页展示版本、大小与更新日志

更早的版本

  • 账号体系：邮箱验证码注册、Google 登录、收藏与歌单云端同步
  • 歌单导入：支持网易云、QQ 音乐、汽水音乐公开歌单
  • 多平台聚合搜索与去重、歌词同步滚动
  • Windows 桌面端与 Android 客户端
