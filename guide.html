使用指南

这份指南覆盖 Halo Music 的主要操作。所有功能都可以在浏览器里直接使用，不需要安装任何东西。

搜索与播放

  1. 在顶部输入框输入歌名、歌手或关键词，按回车或点「搜索」。
  2. 结果会同时来自多个平台并自动去重；点击任意一首即可播放。
  3. 歌曲加载失败时会自动尝试其它可用音源；若所有音源都不可用，会自动跳到下一首。

播放器状态会显示「加载音源中 / 播放中 / 已暂停 / 缓冲中 / 播放失败」，方便判断当前情况。

快捷键

  • Space：播放 / 暂停
  • P / N：上一首 / 下一首
  • F：收藏当前歌曲
  • ← / →：快退 / 快进 5 秒（按住可连续调整）
  • ↑ / ↓：音量加减 5%
  • M：静音 / 取消静音

播放队列与歌单

搜索结果每行右侧的按钮可以把歌曲加入播放队列。登录后还可以：

  • 创建、编辑和删除自己的歌单，给歌单加描述
  • 从网易云、QQ 音乐、汽水音乐的公开歌单链接导入歌曲
  • 把收藏与歌单导出为 JSON 文件做备份

听歌分析

登录后，「我的信息」里会显示听歌分析：总播放、总时长、本月播放、最近 7 天趋势、常用收听时段，以及最常听的歌手和歌曲。数据由你自己的播放记录生成，不用于广告画像。

常见问题

  • 为什么有的歌只有几十秒？免费音源对部分版权歌曲只提供试听片段。播放器会检测并尝试切换到完整音源，换不到时自动跳下一首。
  • 为什么有时加载慢？音源来自第三方平台，解析与代理需要时间；失败后会自动重试其它线路。
  • 换设备后收藏还在吗？登录同一账号即可同步收藏与歌单。
  • 能下载音频吗？站内不提供音频文件下载，下载按钮仅用于把搜索结果加入本地收藏备份。
